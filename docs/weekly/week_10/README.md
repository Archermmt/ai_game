- `features/audio/world_audio.gd`：场景内播放器与资源缓存，不新增自动加载、不修改共享总线。只有成功发布的源事务产生材质音，预览保持安静。

## 缺陷与结果记录

**W10-A01，已修复。** 原生混音捕获证明将音量设为 −80 dB 仍留有约 0.0000236 峰值。修复为暂停环境循环、停止效果声和音乐。最终复测 CoreAudio：24次四类操作音、181248 帧、最大音量峰值约 0.228，全部静音输出为 0。资源侧另做所有声部最坏相位/四效果重叠保守上界 0.9212，保留约 0.71 dB 余量。软件输出验证不替代耳机听感。

**W10-U01，已修复。** 150% 设置弹窗曾继承已缩放 HUD 的 Canvas 变换，出现二次位移、下缘超出屏幕。弹窗改由未缩放的场景根持有，保留独立内容缩放与滚动；新增窗口归属/边界、三个真实滑杆信号回归，并保留原生 1080p 截图。

**W10-P01，已优化，门槛仍开放。** 容量源微基准：地形校验约 15.116 → 4.095 ms，完整校验 31.801 → 20.759 ms，工作线程评估 53.331 → 40.633 ms（同机五次平均）。10 秒原生诊断的完整容量提交最大值约 255.956 → 224.709 ms，仍高于 150 ms；这组短诊断不替代正式 60 秒探针。继续保存最大值，不排除首次提交，不降低对象数量以宣称完整容量通过。

最终累计用例、60 秒原生指标、发布包与无缓存提交号见同目录 `delivery.json` 及自动化证据。存在外部门槛时仅称“冻结候选”，不称 M4/M5 全部通过。
