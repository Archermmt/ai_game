# UX-03 已知边界与未关闭门槛

- 屋顶当前支持山墙/圆锥的独立高度及平顶切换。没有任意屋脊、四坡顶、自由裁剪、城垛或屋面布尔；沿用原矩形/圆形房屋朝向限制。
- 门窗在同一父屋墙面移动，窗可改变离地高度，门保持接地；窗高0.35–1.79m，门高1.8–3.5m（并受墙高/间距限制），避免原素材按1.8m分类时把高窗误换成门；跨房屋重新附着及已脱离父屋的内容继续使用旧恢复入口。圆墙仍遵守原洞口边界/间距规则，不能跨周长接缝制造无效洞口。
- 桥与短阶沿用已有跨度、高差、岸线和建筑保护。不能把桥头拖进水中或通过修改绕过规则；原已失效结构保留问题提示，修改后的新状态须合法。
- 路径、池域、围栏仍使用原创建/参数工具；本轮新增的悬停表面编辑覆盖房屋、屋顶、附着门窗、桥阶和手放物件。
- 手柄为屏幕投影的32逻辑像素控件，并非完全按深度遮挡的3D箭头。源拾取采用最近可见墙/屋面/开口与结构边界；手放资产用已有wrapper碰撞界限，不能将透明树叶的像素轮廓当作精确拾取。
- 局部编辑p95≤150ms、全新设备冷启动、Windows/最低配置实机、人工触摸板/听音、远端CI、十名首次玩家仍独立开放。自动注入Input不是人工测试，macOS导出也不代表Windows实机通过。实际首次玩家0/10，M4/M5未批准。
