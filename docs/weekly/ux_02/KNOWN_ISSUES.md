# UX-02 已知限制

- 本次目标是统一现有MVP交互；建筑仍为矩形/圆形、固定朝向。自由屋顶、任意裁剪、多选分组旋转、逐对象染色及可移动地形块属于后续UX-02-B。
- 橡皮点删房屋/手放物件；池域、路径和结构删除在精确入口。外围派生植物和地表动态草不是可点删源物件。
- 手柄采用屏幕投影与局部白色轮廓；拖动时仅显示当前手柄。没有新增遮挡深度检测或原版自由几何系统。
- 24屋/1000源实例、有选择手柄、45%动态草的最终60秒测量：局部提交p95为277.353ms，高于150ms目标。帧p95为11.494ms、主回调最大45.751ms、RSS峰值948.73MiB；此项继续开放。
- Windows仅完成打包格式检查，不代表Windows实机通过。最低配置PC、物理Mac触摸板、人工听音、远端CI、十名首次玩家仍待验证；实际首次玩家0/10，M4/M5未批准。
- macOS首次导出在并行回归负载下首绘35.955秒，结束回归后串行复测2.710秒；两次记录均保留。后者有本机既有缓存，不能关闭全新设备冷启动门槛。新UI输入证据来自原生窗口内注入真实Input事件，并非人工触摸板操作。
- 指定B站视频页面可核对标题、作者、日期、时长，捕获的播放画面为黑色，未获得可验证操作帧；没有把其他教程截图当作该视频画面。设计依据与原版截图链接见调查记录。
