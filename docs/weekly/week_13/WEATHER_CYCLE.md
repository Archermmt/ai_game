# 明早按钮与四季随机天气

按用户要求扩展当前主场景，不改写原批准PRD。源码版本与最终测试结果见本文末尾。

日历新增**明早6:00**按钮：无论现在几点，都跳到第二天6:00，支持月末、年末和季节交界；保留当前时间倍速或暂停状态。到最大年份最后一天时禁用，避免日期溢出。

自动天气在每3个游戏小时的整点窗口重新抽取（00/03/06/09/12/15/18/21），因此一天内也会变化；跨日和“明早”按钮会按新日期季节抽取。暂停/摄影冻结时不自动抽取。随机结果可以与上一段相同，不强制换一种天气；100%指定天气也会一直出现该天气。

## 在底栏设置比例

点击底部**太阳图标**打开“四季天气比例”。季节下拉选择要配置的春/夏/秋/冬，分别保存各自比例；不改变当前游戏日期。拖动某个滑块，其余按原比例分摊剩余值，实际总和始终100%。某项100%后往回拖，会把剩余比例分给晴（若调整的是晴，则分给阴），不会产生全零无解状态。

不适合该季节的天气置灰，不可修改或抽中；顶部天气图标的手动菜单也禁用对应项。春夏秋不出现雪/暴风雪；冬季不出现雨/暴风雨/沙尘暴。旧档有不合季节天气时迁移为兼容天气：冬雨→雪，冬暴风雨→暴风雪，非冬雪→阴，冬沙尘暴→雾。

勾选“自动天气”按游戏时间抽取，取消则保持手动天气（跨季仍遵守限制）。比例更改影响后续抽取，不立即覆盖当前天气；可用顶部图标手动预览。

## 表现与性能边界

新增雾、暴风雨、暴风雪和沙尘暴的原创图标、光照/天空/雾色和GPU粒子表现。暴风雨雨线更快更密、闪电间隔约6秒；暴风雪横吹雪粒、低能见度与更重雪色；沙尘暴有棕金色浮尘、雾幕与风声；雾天使用冷色低能见度。恶劣天气提高原风声层，音乐进一步压低，保持环境前景。没有新增独立雨声或雷声音频资源。

雨1400、雪900、尘700个固定MultiMesh预算，同一时刻只显示对应一种；雾不增加粒子。无逐粒子CPU更新，也不重建地形/树木几何。减少动态禁止闪电并放慢粒子，摄影冻结天气相位和时间。未改Blender源件、未新增插件。

## 数据与兼容

CalendarState保存自动开关、四季比例、种子与当前游戏时间窗口，路径为`presentation.calendar.weather_cycle`。种子+时间窗口决定抽取结果，大步推进与逐步推进、存档前后续玩得到相同结果，不依赖帧数或现实日期。每次推进只计算最终窗口，不循环处理跳过的每一分钟。

旧档缺少配置时使用默认比例。非法数值、非100%总和和禁用天气非零比例拒绝加载且保留原状态。手动日期、比例和开关通过原表现保存管线标记未保存，不产生建造历史；自动时间/天气流逝不污染世界源或撤销记录。

## 复验命令

```bash
python3 tools/quality/week_thirteen_checks.py
python3 tools/quality/week_thirteen_native_checks.py
python3 tools/quality/seasonal_music_native_checks.py
python3 tools/quality/seasonal_music_mix_checks.py --driver CoreAudio
python3 tools/quality/weather_budget_checks.py
```

前三类原生检查串行执行。界面与性能使用Dummy，内部音乐混音另用当前macOS CoreAudio；不宣称物理听感或Windows真机通过。恶劣天气容量检查每种30秒、24屋/1000源，检查帧p95与RSS；不代替原60秒编辑提交基准，既有首笔尖峰仍保持开放。

初次旧回归在1月选择雨并断言雨，现因季节限制正确被拒绝；将该旧测试改为1月选择雪，并另增季节禁用/迁移回归。失败日志保留在证据目录，未移除功能断言。
