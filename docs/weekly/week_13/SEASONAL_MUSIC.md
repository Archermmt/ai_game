## 柔和与音量

离线6500Hz低通、响度目标-24 LUFS、真峰值上限-4dBTP、MP3 128kbps立体声48kHz。编码后实测集成响度-24.75至-23.37 LUFS、真峰值≤-9.55dBTP；清单记录各首实际值。运行时最大线性增益0.12，默认音乐滑块50%，候选稳定2秒后起播，再约6秒完全进入；切歌6秒交叉渐变；滑块关闭最多3秒淡出，退出1.2秒淡出后再释放混音资源。

阴天降至85%，雨天50%，雪天65%，夜间再乘70%，变化约2秒过渡；环境和操作音量不改动。天气本轮只驱动音乐压低，未新增雨/雷音效。音乐沿用现有设置滑块，不新加面板。

新主场景首次使用本功能时，一次性将历史默认关闭的音乐设为50%，并写入`seasonal_music_initialized`偏好；后续保留音乐调节与0关闭。旧周场景仍使用旧音频默认。标记是本地偏好，不进入作品或撤销历史；QA不写正式偏好。用户主动重置设置会重新采用此默认。

## 实现和复验

`features/audio/seasonal_music.gd`负责候选池、双声部淡化、静音与释放；当前LivingPlayground提供日历与偏好。旧合成音乐在新主场景禁用，环境/水声/操作音继续由WorldAudio管理。预载8个压缩流（约26MiB资产），仅两条声部解码，不运行ffmpeg、不逐帧读取磁盘、不新增插件。

```bash
python3 tools/quality/week_thirteen_checks.py
python3 tools/quality/validate_seasonal_music.py
# 原生音频逻辑探针，显式Dummy；仍需物理听音
python3 tools/quality/seasonal_music_native_checks.py
# 重新制作派生文件；原始曲目需仍在指定目录，依赖ffmpeg/ffprobe
python3 tools/audio/prepare_seasonal_music.py --source /Users/tongmeng/Desktop/enjoy/music
```
