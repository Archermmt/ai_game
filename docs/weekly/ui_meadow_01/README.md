# UI / Meadow 01 · 底部卡片、远景柔焦与动态地表草

用户于2026-10-21提供Tiny Glade底部栏截图，要求控制界面融入场景、点击创建/修改、远处虚焦，并可拖动调整动态草密度。本补充记录该明确范围调整；不覆盖批准PRD，不计作W11首次玩家测试，也不关闭原有性能/真机门槛。

默认入口 `app/garden_root.tscn`，版本 `0.10.1-garden01`，继承W10事务、存档、摄影和声音。相机输入继续为双指移动旋转、捏合缩放、Option+左键平移。

## 使用

- 底部12张原创色卡：建造、石径、门窗、色板、修改、地形、花草、树木、池岸、道具、摄影、光线。点击工具卡即可激活该类的默认工具并展开选项；卡内可换具体工具。关闭选项后仍保留当前工具高亮。
- 点击「修改」再点小屋或物件，展开对应属性；修改后沿用既有预览/提交/撤销。创建矩形/圆屋、画路径、放门窗、刷植等都进入已有事务。
- 右上角保留撤销、重做、作品与设置；常驻左右大面板收起，参数按需展开，长内容可滚动。150%界面与摄影隐藏/恢复已纳入验证。
- 点击底部「花草」（叶片图标），拖动 **地表动态草** 滑杆：0关闭，默认45%，100%最高。滑杆只调本机派生草层；手工种下的花草、树木和道具保留。分类笔刷的类别/半径/密度仍有各自控件。
- 设置中的 **远景柔焦** 默认开启，可关闭；焦点跟随相机缩放，主屋与编辑区域保持可读，远方树幕柔化。该偏好与草密度都不进入作品源或撤销历史。

## 模块与性能约束

| 模块 | 行为 |
| --- | --- |
| GardenHud | 复用原属性/存档/摄影控件和信号，增加原创SVG卡片；隐藏旧常驻面板，以场景根持有弹窗避免重复缩放 |
| GardenPlayground | 组合新HUD、焦距、草层；修改模式按房屋包围体/物件拾取体选取，提交期间不打断已释放事务 |
| MeadowData | 隔离种子的抖动网格，最多40000个候选；避开房屋、门口、曲线路径、池岸、桥阶与生活道具；高度来自同一TerrainField |
| MeadowRenderer | 最多36个8m MultiMesh块；共用9三角/簇的草网格和一份风材质，无每簇Node/碰撞/实时投影；远处逐步收起 |
| 生成与拖动 | 一个后台任务加最新待处理快照，主线程约2ms分片准备并整体替换；密度改变只调整稳定随机前缀的可见数量，无重洗/重建；关闭期间有编辑，重开时重建最新避让 |
| 动态 | 与场景风量/风向、减少动态及摄影冻结统一；风量0静止，摄影导出使用同一World3D和相机景深 |

SVG与网格/着色器为项目原创；图标源在 `art_source/ui_meadow_01/`，可由 `tools/art/build_garden_ui.py` 重建。草网格的可编辑源为 `MeadowData.blade_mesh()` 代码，不新增Blender模型或外部插件。旧P0对象ID、schema/generator和正式存档路径保留。
