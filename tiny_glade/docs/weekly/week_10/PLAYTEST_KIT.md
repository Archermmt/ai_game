# 首次玩家试玩准备（T067，供 W11 使用）

2026-10-21。当前美术由用户接受，使用 W10 候选包。正式十人测试安排在 M4 冻结通过后；本文件是执行材料，不代表已有玩家或招募结果。尚未联系任何外部人员。

## 人员与执行

目标十名未接触过本作的玩家，记录系统、输入设备、是否玩过建造游戏。建议 Mac 触摸板、Mac 鼠标、Windows 鼠标均覆盖，避免全部来自开发团队。每人约 20 分钟，由主持人旁观，先取得录屏/匿名记录许可；不记录姓名、联系方式或其他无关信息。发生数据丢失、崩溃、无法返回编辑时立刻停止该轮并归档复现。

每人使用独立 QA 存档目录或独立系统账号，不使用开发者正式作品。开场只说“这是一个没有输赢的林间建造试玩，请一边操作一边说出想法”；主持人不要先讲按钮位置。卡住 60 秒可以提供一次提示并记录时间。

## 顺序与观察

| 时间 | 给玩家的任务 | 记录 |
| --- | --- | --- |
| 0–3 分 | 进入示范坡地，观察小屋前后和池边 | 首次旋转、平移、缩放耗时；手势误解；是否误画 |
| 3–7 分 | 建一间房，改变尺寸，加一扇窗，再撤销与重做 | 找入口时间、首次成功、错误反馈可理解性 |
| 7–11 分 | 画一条路，种一片植物，放一个生活道具 | 预览/提交区别、对象遮挡、帧卡顿 |
| 11–14 分 | 保存作品，修改后载入原作品 | 是否理解槽位与未保存提示，是否有内容丢失 |
| 14–17 分 | 设置 UI 150%、减少动态，调低环境声，关闭音乐 | 能否找到、是否截断、音量是否立即生效 |
| 17–20 分 | 摄影输出一张图，再回编辑 | 图片路径、是否带 UI、相机恢复是否符合预期 |

主持人另做受控异常验证：池边冲突、锁窗尺寸冲突、存档中断恢复。不要让首次玩家手工破坏文件。

## 汇总和进入 W11

按问题合并，不按玩家数复制十条相同任务。问题单包含触发操作、期望/实际、设备、复现率、影响、证据、回归测试及负责人。P0 数据/事务问题优先；可见性与输入阻塞其次；P1 新玩法不混入冻结修复。

正式门槛：十份有效首次玩家记录、Windows 真机记录、P0 清零及修复后回归。当前实际玩家数 **0/10**。局部编辑 150 ms 性能门槛和真机门槛仍需独立确认，不能从自动化用例数推断通过。
