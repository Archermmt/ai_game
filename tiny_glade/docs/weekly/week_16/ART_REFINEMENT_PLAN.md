# W16 · 林中小屋美术精修计划

用户于 2026-11-11 授权按 Tiny Glade 对比结论实施。沿用温馨林中小屋方向、原创程序资产、现有音乐和全部玩法；不修改批准 PRD，不扩展建筑组合规则。参考的是造型与衔接品质，不复制商业资源。

| 阶段 | 实施内容 | 可验收节点 |
| --- | --- | --- |
| A0 基线 | 保存同机位春景和编辑界面，记录源/存档保护边界 | 对照图可打开，计划入库 |
| A1 建筑 | 梁木断面与弯曲变化、窗台厚度、门口门槛、灰泥大色块和细微起伏 | 近景可看清收边；矩形/圆形、开口、贴靠及改尺寸不穿洞、不改源；合并绘制 |
| A2 环境衔接 | 根据实际墙脚、树根和池岸生成低矮地被；池岸加入疏密有别的莎草；入口、路径、桥、玩家物件避让 | 搬屋、改路、改池和撤销后重建；不向存档写装饰；冬季地被埋雪；近景能看见岸带和墙脚过渡 |
| A3 植被与构图 | 调整叶簇轮廓、减少重复斑点，草地形成长短相间的草甸；示范林缘打散行列、打开小屋视线；保留微缩景深 | 同机位春/暮/秋雾/冬与近景可体验；老作品不迁移或改摆放；空地和示范庭园均合法 |
| A4 回归交付 | 正式 Metal 主场景实拍、编辑/撤销/存读档/漫步/摄影与累计回归，更新状态和证据，提交里程碑 | 非空测试全通过，错误必须失败；报告列出实际计数、命令和未验门槛 |
