# W09 · 15 分钟首次体验脚本

使用当前 `project.godot` 或 W09 Mac 发布包，1080p，先选择示范布局。
此表是人工体验复现步骤；自动场景/事务测试另有证据，不冒充人工计时结果。
每个阶段失败时保留原作品、操作和截图，停止把失败步骤计为通过。

| 时间 | 操作与可观察结果 |
| --- | --- |
| 0–2 min | 默认入口显示原生示范图；选择示范。双指水平/竖直移动分别改变水平角/俯仰；拉开/收拢只缩放；Option+左键平移，不创建物件；移至工具栏后释放不会继续拖动。 |
| 2–4 min | 点选择布局，进空布局（有改动时选择取消，再次进入并明确放弃）。地形及外围树保留；跳过一句话提示，工具仍全部可用。拖矩形/圆形小屋，调整大小和高度，撤销/重做。 |
| 4–6 min | 路径末端接墙生成门；锁门，再删路，门保留。手放窗后接路，窗不被覆盖。检查提示与恢复入口可见。 |
| 6–8 min | 刷坡并撤销；测试 3 m 基座边界、超界整笔拒绝。画池并放桥；扩大池岸使桥失效，桥仍显示问题；撤销同时恢复池岸和桥头。 |
| 8–10 min | 摆道具、刷花草、改变附近建筑；手工物件及远处植被不漂移。删除含手窗的父建筑，检查待附着入口，撤销恢复。 |
| 10–12 min | 摄影：隐藏编辑 UI/轮廓，选择冻结/恢复动态，改变构图并保存书签；分别输出 1080p、2K；先用不存在目录失败，再选可写目录重试。图片能打开且没有 UI。Esc 返回精确进入前相机、选择状态保留。 |
| 12–14 min | 我的作品中明确选择槽位、命名保存；已有作品必须出现覆盖确认；取消后原作品保留。载入后书签存在、用户缩略图替换模板图。 |
| 14–15 min | 修改作品再切换布局/退出，三选提示可取消；保存并继续正确执行。重启载入作品。100/150% 界面及摄影滚动区按钮均可触达。 |

物理触控板方向/灵敏度、真实 Windows 输入与最低配置测试仍需对应设备确认。
