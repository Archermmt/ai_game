# I4：建筑、共享骨架与界面美术

2026-10-29。六建筑家族补木构/UV/材质；温室以透明玻璃保留框架与内部盆栽。四位居民共享九骨骼、真实Skin/权重、端茶挂点；同一控制器覆盖走路、坐姿、坐下/起身过渡、端茶与俯身观察。材质表面按颜色合并，动画与摄影时间一致。源件ResidentRig可再生成，导出四个带Skin的GLB；不是借用外部动作库。

树冠采用生成叶簇的竖直交叉叶卡与水平冠层，保留两种形态、风动和Alpha Scissor。原始透明PNG与完整提示词见[生成记录](../art_i3/LEAF_IMAGEGEN.md)，使用内置imagegen，没有CLI回退或图像后处理。

21个工具缩略图由实际模型渲染，保存在game/ui/icons；界面已接入缩略图并默认折叠手记，保留按钮/Tab入口。图标源生成器game/art_lab/icon_baker.gd。环境补天空反射、轻雾，船只跟随统一时钟轻摇。

四套Skin/骨骼、动作、挂点、暂停姿态测试与两渲染器实际编辑/摄影回归通过；六机位均保存。Compatibility短样本帧间隔p95 13.983ms，编辑p95 66.240ms。

这里交付了可体验的正式适配第一版，但未替用户完成G1视觉接受；动作尚无挥手/浇水完整片段库，完整111条资产也未逐条验收。后续I5补构图/反馈与动态证据，I6做映射与容量复核。
