# I3：分块草层与浅湾水面

2026-10-29。固定种子4271，抖动格候选、低频成簇密度、地基/道路/坡度/岸边过滤；按8m块发布MultiMesh。底色、短草、草束、野花与树冠形成层次。草卡使用内置imagegen生成的透明原图，提示词与落盘路径见[IMAGEGEN](IMAGEGEN.md)；使用Alpha Scissor及mipmap。正交远景使用稳定排序的密度LOD，不是共享蒙皮或几何LOD。

水使用源高度/岸距场、深浅、法线、高光与连续窄白沫，移除周期亮点与球体泡沫。岸距双向传播更新，波/风使用统一clock；暂停、减少动态与摄影停止推进，避免TIME独立走动。当前是自有浅湾样板，尚无SSR/平面反射，不能宣称完整倒影通过。

稳定种子/变换、地基道路避让、贴地与撤销测试，以及两渲染器六机位/编辑摄影通过。本机Compatibility帧间隔p95 14.315ms；编辑p95 65.168ms，非目标设备/压力结论。
