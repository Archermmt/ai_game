# 开发进度

## 当前可体验版本

当前是**基础功能与美术原型可体验版**，可双击项目根目录的 `play.command`，或执行 `godot --path .`。欢迎页可直接进入布置好的海湾，也可从空海面开始。2026-10-29对照用户提供的官方画面后，明确当前视觉质量仍有较大差距，不记为参考级美术通过。

**当前已交付美术改良I1的本机部分**：固定六机位、颜色/GLB校准、材质保真与渲染对照，见 [I1记录](art_i1/I1_REPORT.md)。下一周I2做连续海岸、统一表面采样及主屋/树/岩首批样板，已细化到开发计划11.6。外部资产与插件仍是未下载候选；目标M1/Windows仍待测。

- 当前含六种建筑外观、四种居民形象、猫与海鸥、花草家具、跨桥小岛、六种生活手记、声音、存档与拍照。
- [操作与启动](../README.md) · [基础美术说明](BASIC_ART.md) · [最新实际截图](../snapshots/week_05.png) · [验证记录](reports/playable_validation.md)。
- 以下第1–4周段落保留当时状态；以本段及第5周说明为当前状态。完整PRD生产资产与发行验收仍未全部完成。

### 当前验收边界与后续缺口

本轮交付三个逐周功能原型和三次提交，**不能把开发计划 M0/M1 全部验收标为通过**：

- 正式 GLB 建筑套件、共享蒙皮骨架与待机/走路动画未制作；当前为程序生成样板，不修改美术清单 planned 状态。
- 圆角岸缘、桥栏杆、坡道的正式连续网格表现尚缺；格路网已实现高差判定。
- 单船目前为停泊模型与调度逻辑，未实现由外海驶入的完整动画。
- 居民当前只验证入住与恢复，随机散步、工作/茶歇属于后续阶段；复杂改地形后的原连通区域站位恢复还需加强。
- 保存提供一个自动/手动共用档与上一备份；3手动槽/3自动备份及完整故障注入留待计划 M3/M4。无跨会话撤销。
- 运行检查设备为 Apple M4 Pro/OpenGL Compatibility，并非 PRD 的 M1/8GB；Windows、目标设备性能和人工完整交互验收未完成。
- Godot 4.7 编辑器命令行导入退出曾出现原生线程清理崩溃；实际游戏运行与三个 headless 规则测试正常。保留此环境问题，不将编辑器退出当作游戏测试通过的依据。
