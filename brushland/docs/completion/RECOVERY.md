# R3 保存与生活闭环修正

世界源数据、运行中的居民、瞬时动画分别处理。JSON写入前校验所有关键类型、有限值、坐标/长度/ID/枚举、世界布局与照片相机范围；失败不修改实时世界、历史或居民。读取最多8MiB，先在候选世界验证再提交。

写入经可替换IO边界：临时写入和flush→滚动3份完整备份→原子替换主档。测试注入部分写入、备份复制失败和最终替换失败；旧主档字节不变、仍可载入，恢复IO后下一次保存成功。临时失败不会被当作主档。原schema1可向后读取，新增元数据为可选。

存档包含相机/缩放/设置、命名槽名、愿望收起与完成状态，三个手动槽独立。瞬时路线/活动预约不直接恢复，按当前世界重新校验；靠泊阶段从合法岸端重入，身份和已预约床位保持。改图/重载清空历史但不回撤已发生的手记，编辑撤销只恢复世界。

本轮修复码头岸端/桥头不能接路，新增精确入住阻断原因、内湖开口验证、桥中央拆除安全迁移；来客先计人数与床位，在泊位做单船短靠泊、可暂停并取消失效目标。居民ID稳定推导偏好，每三次选活动优先一次，其他选择继续轮换。受阻预览显示斜纹和原因，可放居所显示预计变体。

`python3 tools/run_completion_tests.py`依次运行11项规则/故障回归及4项原生交互。结果在completion_r3的core_tests.json/native_tests.json和日志，逐项范围见AC_TRACEABILITY。16类损坏档、50次混合undo/redo、6愿望自然模拟、在途拆屋保存重载等均通过。原生靠泊截图在snapshots/completion/arrival_boat.png。

这些故障测试只使用独立user://test文件，不修改用户主存档或文件权限。未通过操作系统强行断电来伪造异常退出证据；真实退出、权限策略与全工具鼠标操作仍在转交步骤中人工复核。
