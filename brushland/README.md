# 风屿手记 / Breezely Isles

Godot 4.7 stable，Compatibility renderer。运行 `godot --path .` 或在编辑器导入 project.godot。

玩法：左键拖画、右键/Esc取消、WASD平移、Q/E转相机、滚轮缩放、方括号调笔刷、Ctrl/Cmd+Z撤销、加Shift重做。工具栏切工具。

按功能组织：game/world 保存纯数据，game/building 放建筑规则，game/resident 放居民逻辑，game/island.gd 负责场景内组装。
