# 奇幻熔岩植物 · 创作计划

以 EmacE Art 的展示图为构图基准。建立可环绕的原创三维峡谷。前景左方的大钩形提灯草、下方流向远处的蓝色水道、右下方紫岩坡以及中远景连续山墙，是第一轮白模的四个定位物。[原作展示页](https://store.godotengine.org/asset/emace-art/lava-plants-free-low-poly-pack/)

| 阶段 | 制作内容 | 交付与验收 |
| --- | --- | --- |
| 构图 | 在 16:9 取景中按左前大株、水道、两侧岸和远山天际线的位置调整透视相机 | 主株灯头落在画面宽约 17%、高约 35% 处。水道贯穿前中景，远山遮住地平线 |
| 资产样板 | 原创三种花型。制作有粗细变化的弯茎、分节花萼、亮黄色垂滴、低矮弧芽。岩壁用不规则断面 | 粗茎到细梢自然收窄，灯头朝下，背光可分辨花萼和黄色核心 |
| 材质样板 | 每种岩体保留大面法线、顶面与侧面的颜色差，区分暗紫岸、暖橘岩柱、蓝紫凹面。水体用青色到靛蓝的深度渐变 | 主光照亮朝天暖岩面；黄色仅集中于花心/滴池；在截图缩略图中能看清植株 |
| 布景 | 地形与水岸以同一条导向曲线制作，将矮芽、凝结滴、弯茎簇沿岸重复，近景留水面负空间 | 近大远小，岸坡遮挡根部；岩群后方再搭独立远景轮廓 |
| 复核 | 从锁定相机渲染，再左右转动，修正露底、遮挡、光色和轮廓 | 保留真实首稿、终稿和复盘；手册写明资产尺寸、拓扑、材质、命名与重建步骤 |

截图库的高分辨率展示图保存在知识库「附件/美术/奇幻熔岩植物-参考图.jpg」。执行从资产分件和可测轮廓开始，用脚本构造可编辑的模型，不引入原作资产包。风格参考、遮挡面推测和最终 Godot 实拍各自留有来源。
