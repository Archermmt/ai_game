# 温馨林中小屋创作计划

以本目录的原始截图为主视角目标。画面为晚春森林中的半木结构小屋，前景金黄叶团围住中央草地，后方多层树冠偏冷绿，右侧有浅池，两个小人物在门前交谈。左侧参数面板、右上署名是视频叠层。核对渲染时只比较场景区域。参考视频的时间点为 00:15。[原始截图](reference.jpg) · [原视频](https://www.bilibili.com/video/BV1dRnU6HE4t/?t=15)

| 阶段 | 制作动作 | 通过条件 |
| --- | --- | --- |
| 定镜头 | 依据 854 × 478 画面，把屋顶、烟囱、地面人物和池心分开标定。先画小屋与池，再生长林缘 | 小屋在水平中央、人物在下方偏左、池塘在右下；主要轮廓没有前景遮挡 |
| 木构与石板 | 用分组网格制作木骨架、红灰抹灰、青灰瓦顶、屋顶窗、烟囱、门廊、石阶与石路 | 在目标截图大小能辨认坡屋顶、梁柱和深色门洞 |
| 林缘与草甸 | 离线固定种子布置林缘；树干按高度分枝，叶团外层用有尖叶的剪影、内部用相邻色块；草甸叠加低矮草笔触和成簇野花 | 后排深林、中央亮草、前方左右亮叶帘分别可读，林冠有局部开口 |
| 环境与人 | 一盏斜射太阳、低强度蓝绿补光和距离雾；独立水面、岩边、浅水浮叶、细烟和相对尺度正确的人物 | 房屋处于半阴，池面仍有水色；两个人物独立站立且方向不同 |
| 导出与复验 | 原创几何离线合并并保存 glTF 2.0；在 Godot 编辑器及真实 GPU 中截取主视角、对照原图调色与调整构图 | 交付可启动场景、原始 GPU 截图、重建源与注明实际差异的美工手册 |

采用可确定重建的形状设计。可见表面优先遵循原图；被遮挡的后墙、背坡、池底与树冠背面按可环绕的三维结构补全。林空、烟囱剪影以及房屋、池、人三者的相对距离都在主相机下复核。
