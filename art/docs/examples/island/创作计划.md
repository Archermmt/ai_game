# 暮色湖岛创作计划

依据[原始帧](reference.jpg)建立一座完整可环绕的微缩湖岛。原笔记标记为视频 06:20；图像尺寸 852 × 480，下沿任务栏和左上水印不参与验收。可用内容区域约 852 × 457。

| 阶段 | 制作内容 | 对照依据 |
| --- | --- | --- |
| 构图 | 锁定低俯角相机；岛心略偏左，下部为倒影，水平线接近上 1/7。 | 本岛约 x205–563、y237–340，树冠 x345–526、y16–166，屋顶 x289–462、y157–232。 |
| 几何 | 不规则岸线、草覆盖土层、右岸巨石、小木栏、睡莲、弯道、两只羊。 | 岸边草花与石头产生细小节奏，地形前沿落入水线。 |
| 建筑 | 米黄色灰泥墙、露明木筋、红陶瓦屋面、前突山墙、门廊、屋顶老虎窗与砖烟囱。 | 尖顶与多层次红瓦是视觉中心。 |
| 植被与灯光 | 单棵高大暖色树、重叠叶团与碎叶，烟囱飘烟；金色侧光、蓝紫背光与暖灰天空。 | 房屋与明亮树冠形成清楚剪影，湖面亮度随距离过渡。 |
| 湖面 | 在相同水线下反射实体几何，用湖面薄层统一色彩，留下截断于屏幕下缘的树与房屋倒影。 | 镜像上下关系与水线相接，保留轻微波纹。 |
| 检查 | 运行 Godot，固定角度输出 PNG，对焦点位置、轮廓、明度与倒影逐项回修，另做环绕检查。 | 截图、场景、可重建几何与面向美术的制作手册一并交付。 |
